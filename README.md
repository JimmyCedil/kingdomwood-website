# KingdomWood Home Service

A website demo for KingdomWood Home Service LLC, built with HTML, CSS, and JavaScript.

Open `index.html` in a browser to try the demo. No installation or build is needed.

Choose a service and select **Ask about this service** to carry that selection into the inquiry form. The form opens an email draft for review. The porch image is an illustrative concept.

To host with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save.
